# Global Claude Rules

## Communication Rules

1. **Never guess or assume** - If unsure about anything, ask the user first
2. **Question mark = question** - When the user ends with `?`, they are asking a question, not giving a command. Answer or clarify rather than execute
3. **Multiple questions = wizard** - When needing to ask more than one question, use the AskUserQuestion tool with multiple questions (wizard-style) rather than asking one at a time
