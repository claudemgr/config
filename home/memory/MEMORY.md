# Memory Index

**Session start:** verify `{project_dir}` = `git rev-parse --show-toplevel`; confirm you are reading memory from within `{project_dir}`, not from `~/.claude/` deployed copies. A `SessionStart` system message names the correct `project_dir` — use it.

**Read this index to the end before following any link.** A reference never replaces the remainder of the file that contains it — read the referenced file, then return to the next line and continue.

- [Image conventions](image_conventions.md) — convert before reading (max 1280px, WebP target, fallback chain: convert→ffmpeg→vips→original); URL images: curl to tempdir→convert→read; never skip conversion
- [gitcommit conventions](gitcommit_conventions.md) — never hardcode path; use `gitcommit` from PATH; auto-creates GitHub remote and sets upstream if repo doesn't exist; COMMIT_MESS message format + emoji map, cadence (one logical change per commit), push behavior (.no_push, `gitcommit push` after offline failure)
- [Comment conventions](comment_conventions.md) — comments always above never inline (≤180 chars); inline exceptions (noqa/type:ignore/nolint, CI SHA-pin annotations for Renovate); never in JSON/.env/CSV/binary; JS `//`+`/* */`, CSS `/* */` only
- [File ending conventions](file_ending_conventions.md) — every text file ends with a single trailing newline (POSIX); exactly one, never blank lines at EOF; exceptions: raw-value secret/token files, verbatim-interpolated files (VERSION-style), mid-line fragment includes, binary/generated artifacts; project formatter wins on conflict; tail -c 1 check + printf fix
- [Shell lifetime conventions](shell_lifetime_conventions.md) — timeout tiers (≤30s/≤120s/≤600s), Bash tool timeout is MILLISECONDS, no unbounded polling/sleeps, no nohup/setsid/disown, `&` requires PID=$! ownership, tail -f/watch only inside timeout
