# Memory Index

**Session start:** verify `{project_dir}` = `git rev-parse --show-toplevel`; confirm you are reading memory from within `{project_dir}`, not from `~/.claude/` deployed copies. A `SessionStart` system message names the correct `project_dir` — use it.

- [Execution hierarchy](execution_hierarchy.md) — QEMU/KVM>Incus>Docker>host; tier purpose, image selection (Docker=alpine, Incus=systemd, QEMU/KVM=full OS), cleanup rules
- [Sensitive data rule](sensitive_data.md) — all public destinations equal (git/pastes/issues/chat/screenshots); masking: preserve key, replace value with xxxxx, never partial values; personal dotfiles is the only exception; pre-flight scan before sharing anywhere
- [Image conventions](image_conventions.md) — convert before reading (max 1280px, WebP target, fallback chain: convert→ffmpeg→vips→original); URL images: curl to tempdir→convert→read; never skip conversion
- [gitcommit conventions](gitcommit_conventions.md) — never hardcode path; use `gitcommit` from PATH
- [Script conventions](script_conventions.md) — shebang/extension determines interpreter (bash vs sh vs zsh vs fish vs ps1 vs cmd); header template, section separators, vim modeline, `__` function prefix, `SCRIPTNAME_` variable prefix, comments above code, no UUOC, builtins over forks, grep `--` separator, exit codes (POSIX 0/1/2 + sysexits 64–78 + signal 128+N), getopts/zparseopts/argparse, NO_COLOR, documentation triple sync (help+man+completions); pipe safety (`[ -t 0 ]` stdin detection, never unconditional stdin reads)

- [Project forbidden files](project_forbidden_files.md) — files/dirs that must never be created; README always README.md, LICENSE always LICENSE.md with 3rd-party attributions at bottom; allowed root files list
- [Standards reference](standards_reference.md) — HTTP status codes (RFC 9110), RFC 7807 error body, ISO 8601/RFC 3339 dates, semver, MIME/Content-Type, UUID v4/v7 (RFC 9562), HTTP security headers, TLS 1.2+ (RFC 8446), JWT RS256/ES256 (RFC 7519), OAuth2+PKCE (RFC 6749/7636), URL conventions (RFC 3986), pagination, Base64url (RFC 4648)
- [.gitignore conventions](gitignore_conventions.md) — header format, ignoredirmessage, standard entries (.gitcommit, .no_push, .no_git, .installed, OS files, dotenv files), project-type additions; .dockerignore and Docker Compose rules are in dockerfile_conventions.md
- [Dockerfile conventions](dockerfile_conventions.md) — two-stage build, ARGs, OCI labels (static+dynamic split), tini entrypoint, rootfs overlay, chmod pattern, health check; Docker Compose file locations, volumes path resolution, dev/prod/test compose patterns (dev=source mount, prod=named volumes, test=tmpfs+named network), AI compose rules; .dockerignore standard entries and per-language additions
- [Logging conventions](logging_conventions.md) — log files are pure raw text always (no ANSI, no emojis); access.log=Apache Combined, auth.log=syslog format, error.log=ISO8601+level, app.log=logfmt; Docker→stdout/stderr; logrotate config required for system services; masking: preserve key, replace value with xxxxx (never partial values)
- [Temp directory conventions](tempdir_conventions.md) — required path structure ({project_org}/{internal_name}-XXXXXX), per-language creation (shell/Go/Rust), OS vars, guarded cleanup, AI rules
- [CI/CD conventions](cicd_conventions.md) — multi-provider (GitHub/GitLab/Gitea/Forgejo/Jenkins); provider detection via git remote URL + API version endpoint; workflow file locations per platform; same gates on all providers; SHA pinning (GitHub/Gitea/Forgejo act runner) and digest pinning (GitLab/Jenkins); truffleHog secret scanning on all platforms; Renovate only (AGPL-3.0, free) — never Dependabot (GitHub-only, creates duplicate PRs); provider CLIs: `gh` (GitHub), `glab` (GitLab), `tea` (Gitea/Forgejo) — prefer over raw curl; `act` (MIT) for local workflow testing only; Jenkinsfile required on every project; release pre-flight: own the tag (delete+recreate); vulnerability scanning mandatory (govulncheck/cargo audit/npm audit/Trivy); critical/high CVE = build failure
- [Go conventions](go_conventions.md) — project layout (src/), Makefile targets (build/release/docker/test/dev/clean), golang:alpine rolling image, CGO_ENABLED=0, 8-platform binary naming, module cache mounts, CommitID ldflags var, ghcr.io registry
- [Rust conventions](rust_conventions.md) — project layout, Makefile targets, rust:alpine rolling image, Docker-only cargo, release profile (lto/strip/panic=abort), no *-sys dynamic linkage, rustls over OpenSSL; error handling: anyhow for binaries, thiserror for libraries, no unwrap()/expect() in library/production code, ? propagation, structured error context
- [Node/TypeScript conventions](node_typescript_conventions.md) — project layout (src/), node:alpine rolling image, tsconfig strict, ESLint zero-warnings, Vitest, package.json script patterns, NO_COLOR, commander/oclif CLI, error handling, code rules (import only, no process.exit in libs, no eval)
- [Python conventions](python_conventions.md) — project layout (src/{package}/), python:alpine rolling image, uv/venv isolation, pyproject.toml, ruff lint+format, mypy --strict, pytest, argparse/typer/click CLI, NO_COLOR, code rules (pathlib, no import *, no eval/exec)
- [Makefile conventions](makefile_conventions.md) — universal cross-language patterns: .PHONY, PROJECTNAME/PROJECTORG inferred from git, VERSION from release.txt, help target pattern, standard target names, variable hygiene (:= vs ?= vs =), Docker run pattern, cross-platform pitfalls, clean rules

- [GitHub conventions](github_conventions.md) — load when `git remote get-url origin` contains `github.com`; CODEOWNERS template, branch protection JSON, issue/PR templates, reusable workflows, matrix fail-fast, secret management, release automation steps, container registry rules (ghcr.io for GitHub, registry.gitlab.com for GitLab)
- [GitLab conventions](gitlab_conventions.md) — load when remote contains `gitlab.com` or API probe `GET /api/v4/version` returns `{"version":"..."}`; `.gitlab-ci.yml` structure, predefined variables, container registry, security stage (truffleHog/govulncheck/policy-check), MR templates, CODEOWNERS at repo root, branch protection via API, Releases API, Renovate as scheduled CI job, self-hosted notes
- [Gitea conventions](gitea_conventions.md) — load when remote does NOT match github.com/gitlab.com and `GET /api/v1/version` returns a version body WITHOUT an `X-Forgejo-Version` response header; `.gitea/workflows/` location, act runner SHA pinning, predefined variables (`gitea.*`), package registry, branch protection via API, Releases API, Renovate scheduled workflow, self-hosted notes
- [Forgejo conventions](forgejo_conventions.md) — load when `GET /api/v1/version` response includes an `X-Forgejo-Version` header OR version string contains `+gitea-`; `.forgejo/workflows/` location (takes precedence over `.gitea/`), predefined variables (`forgejo.*`), runner labels, federation notes, API (compatible with Gitea v1), Renovate with `platform: gitea`, Codeberg = public Forgejo instance
- [UI/UX conventions](ui_ux_conventions.md) — designer mindset, dark-first theme (dark/light/auto), full design token system (surface/text/border/accent/status tokens with pre-checked contrast ratios, CSS variable block, Rust Theme struct, ANSI fallback, mobile equivalents), web (SSR, mobile-first, WCAG 2.1 AA, 44×44px touch), desktop (GUI>TUI>CLI, X11+Wayland, dark-light crate), mobile (iOS/Android/Flutter theme APIs), TUI (alternate screen, NO_COLOR), universal rules
- [Project type conventions](project_type_conventions.md) — rules follow project TYPE not language; server/desktop-gui/tui/cli/library/worker/web each have cross-language requirements; language files answer HOW, type answers WHAT; cli arg parsing includes Node/TS (commander/yargs/oclif); web SSR rule applies to Go/Rust/Python, Node/TS follows its own conventions
- [Security conventions](security_conventions.md) — enumeration mitigation (identical auth messages + constant-time, opaque IDs, no account-existence leak); GeoIP as risk signal only (ip-location-db `-mmdb` npm packages, daily, `{data_dir}/security/geoip/`, never sole gate, privacy=PII); ip-location-db MMDB type strings (`asn ipv4/ipv6/ipvAll`, `city ipv4/ipv6`, `country ipv4/ipv6/ipvAll`) — use `maxminddb-golang` not `geoip2-golang` (geoip2 rejects non-MaxMind type strings); Go struct field tags and usage pattern in security_conventions.md; CVE scanning (govulncheck/cargo audit/npm audit pre-commit, Trivy for containers, `{data_dir}/security/cve|trivy/`); IP/domain blocklists; SECURITY.md requirements for public repos
- [Testing conventions](testing_conventions.md) — unit tests alongside code (`*_test.go`/`#[cfg(test)]`), integration tests in `tests/`; table-driven tests, `t.Run` sub-tests; what belongs in unit vs integration; mock strategy (interfaces, never mocking frameworks required); coverage gates (100% SERVER projects, 60% default); test data in temp dirs; write tests in same commit as code
- [Database conventions](database_conventions.md) — SQLite default (single-node), PostgreSQL for cluster; no migration files (CREATE TABLE IF NOT EXISTS + idempotent ALTER TABLE on startup); parameterized queries always; connection pool limits; transactions with `defer tx.Rollback()`; no `SELECT *`, no destructive schema ops, no raw token/password storage
- [API conventions](api_conventions.md) — route naming (versioned, plural nouns, lowercase, hyphens, no trailing slash, nouns not verbs); path vs query params; JSON response format (2-space indent, trailing newline, `{"ok":true,"data":{...}}`); RFC 7807 error body; X-Request-ID propagation; content negotiation priority; middleware ordering (Allowlist→Blocklist→RateLimit→GeoIP→Auth); API-first rule
